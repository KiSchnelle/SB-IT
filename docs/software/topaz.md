# Using Topaz

## Load Topaz

```bash
spack load topaz
```

Then you can run Topaz commands directly in your terminal.

## Topaz in cryoSPARC

To use Topaz from cryoSPARC, use the Topaz wrapper script:

```text
/appl/scripts/topaz_cryosparc.sh
```

Copy this path into **Path to Topaz executable** — either in the individual cryoSPARC job or once in the
project-wide cryoSPARC settings.

!!! note
    Unless you know what you're doing, keep the default CPU/GPU configuration.
